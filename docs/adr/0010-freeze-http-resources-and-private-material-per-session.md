# ADR 0010：会话固定 HTTP 资源和私密材料

独立 HTTP 插件由宿主管理原文与更新。运行会话固定主设置、按顺序交付的插件原文、编译规则、脚本实际源码/静态检查产物、本机 MITM 设置和 CA 身份。脚本后端的必要能力在启动准备时校验，静态配置验证不创建执行环境。显式重连先准备候选，再经过停止屏障切换。失败恢复保留的旧实际内容，不重新读取已变化的来源。普通 Stop 释放私密材料。节点选择和分流资源更新不应用待修改的 HTTP 配置。

CA 由 Invoke 的独立私密上下文提供，CLI 只传明确的私密文件路径；共享 YAML、普通缓存和可序列化启动快照不承载私钥。Windows 跨进程交付使用绑定启动身份的当前用户 DPAPI sidecar。静态校验和离线演算不获取 CA、不读取外部资源，也不初始化 VPN。

URL、头、正文与脚本配置选择始终按原始 URL（U0），不因修改重新匹配。原生规则与脚本共存：每个方向先执行原生阶段，再串行执行匹配脚本；脚本看到前序成功结果。原生 header/body 保留独立阶段事务；每次脚本的 URL/method/status/header/body 候选整体校验后才接受，失败回到该次调用输入，保留此前成功结果和凭据清理。请求脚本结束后才为最终目标建立业务上游；本地结果不递归进入响应处理。

匹配正文只接收一次，在同一个有界工作区内完成原生与脚本事务。共同收集/解码失败时回放原文；原生转换失败或单次脚本失败不撤销其它已成功阶段。共享工作区在分配前预留，许可随实际缓冲、回放前缀和发送 owner 持有至最后引用释放；传输错误、取消和 Stop 仍作为真实失败处理。JS text 与 bytes 变化分别输出 UTF-8 identity 与 binary identity，无内容变化保留当前表示。平台执行超时不得遗留仍在运行的脚本；观察到 Future 完成不能代替真实结束。
