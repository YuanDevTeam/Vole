# ADR 0010：会话固定 HTTP 资源和私密材料

独立 HTTP 配置的资源更新只产生完整的待应用候选；运行会话固定主设置、实际 payload、编译规则和 CA 身份。显式重连先准备候选，再经过停止屏障切换；失败恢复保留的旧实际内容，不重新读取已变化的来源。普通 Stop 释放私密材料。节点选择和分流资源更新不应用待修改的 HTTP 配置。

CA 由 Invoke 的独立私密上下文提供，CLI 只传明确的私密文件路径；共享 YAML、普通缓存和可序列化启动快照不承载私钥。Windows 跨进程交付使用绑定启动身份的当前用户 DPAPI sidecar。静态校验和离线演算不获取 CA、不读取外部资源，也不初始化 VPN。

URL、头和正文阶段始终按原始 URL 选规则。匹配正文在有界事务内累积，完整成功后才提交输出；格式或工作区不足时回放原文。共享工作区在分配前预留，许可随实际缓冲持有至发送结束；传输错误、取消和 Stop 仍作为真实失败处理。
